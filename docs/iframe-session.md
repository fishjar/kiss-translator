# iframe 翻译会话

主页面 URL 决定整页规则和黑名单。网页翻译、语言、服务和功能开关只有一份目标状态；各文档仅处理自己的 DOM。iframe 地址规则仅在该地址单独打开时匹配。

扩展使用后台协调和 `storage.session`；油猴由主页面协调。注册不等待规则加载，初始化后推送快照。完整导航重置会话，SPA 路由保留本次用户操作中的行为字段，重新匹配选择器等网站结构字段。扩展新增 `webNavigation` 权限，用于区分完整导航和同文档路由变化，不保存浏览历史。

划词面板只在主页面创建。iframe 保留选区监听和轻量触发按钮；跟随选区开启时，iframe 首次打开居中，拖动位置在本页会话内保留，不覆盖主页面的已保存位置。关闭跟随时沿用固定位置设置。输入框按钮和输入快捷键本地执行，弹窗命令定位到最后有效的编辑文档。

## 手动复现

在仓库根目录启动静态 HTTP 服务，通过 `http://localhost:<端口>/testdata/iframe-session.html` 打开测试页。跨域按钮使用同端口的 `127.0.0.1`，不要用 `file:` 页面验证跨域行为。

依次添加同源、跨域嵌套、输入框、空白、srcdoc、沙箱和延迟加载 frame。检查：

- 修改语言或开关后，已有和新建 frame 使用相同目标状态。
- iframe 划词只打开主页面的面板，拖动后再次划词位置不跳回中心。
- iframe 中仅有输入框时可以启动输入翻译，不创建正文翻译器和划词 React 面板。
- SPA 切换保留用户语言选择，刷新恢复网站默认值。
- 页面进入黑名单时停止业务模块，退出黑名单后可以恢复。

| Edge + Violentmonkey 2.50.0 | 实际安装构建后的用户脚本；跨域子 frame 与孙级 frame 显示轻量按钮，点击后主页面显示唯一面板；子 frame 无划词 React 面板                      |
| Edge 扩展后台强制停止后唤醒 | 会话 ID 与状态保留                                                                                                                          |

性能基线为 `d10f2fe7`，两边使用相同划词和输入框开关。启动稳定并主动执行 GC 后采样三秒：

| 场景           | 基线空闲脚本时间 | 改造后空闲脚本时间 | 基线 JS 堆 | 改造后 JS 堆 |
| -------------- | ---------------- | ------------------ | ---------- | ------------ |
| 无 iframe      | 0 ms             | 0 ms               | 10.40 MB   | 10.71 MB     |
| 20 个空 iframe | 0 ms             | 0 ms               | 61.61 MB   | 59.24 MB     |

无 iframe 页面的监听器从 606 个变为 610 个；20 个空 frame 增加约 3 MB 总堆，但没有子 frame React 面板。

这是固定测试页的单次采样，堆大小受 GC 影响，不能据此承诺所有网站的性能或宣称内存优化。核心约束是没有轮询、定期同步或新增的主文档全文扫描；子文档等待阶段只检查新增节点，正文启动后移除等待观察器。

已额外观察到 Edge 中 iframe 输入框在页面失焦后经定向命令和 Microsoft 接口完成“你好，世界”到“Hello, World”的回填。单次服务调用不代表供应商的普遍翻译质量或可用性。Firefox、Thunderbird、移动端触屏及真实视频字幕需在对应环境另行验收。
