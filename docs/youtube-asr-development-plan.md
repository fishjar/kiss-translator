### 继续实施的门槛

1. 以已有正常 Chrome 的整轨成功原型作为下载层基线；工程化后在可正常原生播放的会话回归验证到片尾。随机起点不作为强制门槛，不因无效独立环境未通过而抹去已有成功证据。
2. 整轨下载完成前增量解码连续 PCM，与参考时间对齐误差不超过 100 毫秒。
3. 按所采用的获取路径完成整轨后重封装完整 M4A，独立播放验证无缺段或重复；随机起点路径额外验证乱序补齐。
4. 跨媒体段裁剪逐句 WAV，验证起止时间、声道及首尾。

新增环节未通过时不宣称相关功能完成，不以播放录音或简单拼接零散 MP4 替代验收。从头降级仍应边下载边处理，不必等整片结束才识别。可依据成功原型推进下载层工程化及独立模块测试；AAC 渐进解码、导出和真实 ASR 仍分别需要新增验收，尚不暴露为已完成的正式入口。

### 从头获取降级（2026-10-16 确认）

- 首版允许直接采用从头顺序获取；中间起点属于可选优化，不因其失败阻止具备完整下载能力的版本。现有随机起点探针仍可用于比较及验证一次降级。
- 中间起点在有限恢复后无有效媒体时，本视频、音轨、本轮任务最多降级一次为从头获取；不在两种模式之间循环切换。视频变化、取消、配额不足和不支持的解码格式不触发此降级。
- 从头模式保持一条顺序下载任务。用户拖动只调整识别和翻译的目标，不取消并重新从头下载，不为每次 seek 创建下载器。
- 已缓存的媒体段继续复用；需要从头重放传输时只落盘一次，不重复解码、识别已完成区间。
- 拖动目标尚未下载到时，显示“正在从头获取音频，已获取至 mm:ss，目标 mm:ss”；不能承诺当前位置立即有字幕，不改变播放器播放状态。
- 下载推进到目标后立即优先识别目标，随后向后，再补齐此前遗漏字幕。下载进度与识别/翻译进度分别展示。
- 只有字幕缓存时，字幕仍立即恢复。逐句下载也允许从头获取到句末，拿齐必要数据即裁剪导出，独立单句任务随后停止；完整下载继续至片尾。两者均不重新调用 ASR/翻译。
- 后续导出复用同一缓存和下载任务；一个单句导出结束不能取消其他仍需要音频的识别或导出任务。
- 从头模式同样遵守超时、有限重试、30 秒无进展和空间限制；失败保留字幕并允许手动重试，不进行无限从头重启。

### 缓存最终约定（2026-10-16 确认）

- 只长期缓存整片 ASR 原文、时间戳及译文，音频仍为临时缓存，不增加长期音频保留选项。
- “大部分情况获取一次”指首次字幕处理完整成功、后续命中且未被淘汰/删除/配置失效的情况；再次观看直接恢复双语字幕，不重新下载、解码、识别或翻译。
- 首次仅完成部分字幕则恢复已有内容并继续补齐缺口，不声称所有视频一定只下载一次。
- 临时音频清理后，主动导出句子或整轨仍可能重新从头获取；这不失效字幕缓存，也不重新调用 ASR/翻译。界面明确音频未缓存及当前获取进度，不承诺立即导出。

## 目标与启动规则

- 首版 Chrome/Edge 普通播放页及 Shorts；直播、嵌入页暂不适配。Firefox、油猴保持原字幕及构建兼容。
- 纯扩展，不增加 manifest 权限、网站范围或资源暴露，不引入代理或本机组件。
- 分段文件 ASR，下载、解码、识别、翻译流水执行；完成一个区间即可上屏。
- 开启扩展翻译且配置可用 ASR 后，原文人工字幕优先；只有自动字幕或明确无字幕时自动识别。元数据失败不能当作无字幕。
- 当前视频可以手动启用或关闭 ASR，关闭后不自动重启；换视频恢复默认规则。
- 首次识别下载整条当前音轨，识别优先当前位置至片尾，再补齐遗漏区间。
- 完整字幕缓存命中后直接恢复，不自动下载、解码、识别或翻译；音频导出按需获取。

## 下载、切分与服务

- 参考审查固定版本：yt-dlp 897341241f2bfb2439fe0367f4c7c9ccd29a3828、youtube-dl 956b8c585591b401a543e409accb163eeaaa1193。它们的多客户端/直链路径不是 WEB SABR 的现成修复；本轮不运行 Python 下载器，不引入其他客户端身份。
- 页面若已提供同音轨原生 AAC 直链，可作为候选并验证 Range/文件身份；无 URL 不手工拼接，HLS/DASH 缺失不凭猜测构造。当前样本未发现这些入口。
- MAIN 桥捕获并复用当前视频原生 SABR 上下文，兼容 `fetch(Request)`；不生成 token、不伪装客户端、不接受任意 URL、自有请求不回流。
- 获取器采用锁定版本的 SABR/UMP 库，绑定选中音轨，维护初始化信息、媒体时间索引、重复段和缺口。
- AAC/MP4 使用 MP4Box.js 解复用、WebCodecs 增量解码；运行时检测实际 codec 支持，不将任意碎片交给 `decodeAudioData()`。
- 请求超时 15 秒；网络异常和 5xx 额外重试最多两次，间隔 1、3 秒；鉴权刷新一次，30 秒无进展暂停并提示重试。
- 单声道连续重采样到 16 kHz 后编码 PCM16 WAV；不常驻整片 PCM。
- 服务设置 `asrMaxDurationSeconds` 默认 30，允许 1–300 整数，非法输入阻止保存，旧配置缺失用默认值。
- 实际块上限取服务、模型、文件大小及桥接限制的最小值。不得让本地模型静默裁掉音频后标记成功。
- 20 毫秒能量帧、滚动噪声底及滞回检测，连续低能量 400 毫秒作为停顿。积累至少 1 秒可切开，尾部保留接下一批。
- 达到时长上限，在末尾 1 秒选择低能量帧边界，无明显低谷则按上限切开；EOF 提交残余语音，纯静音计入覆盖但不调用 ASR。
- 不重叠、不加前后文、不去重文本、不跨缺口拼接，不承诺语义上的完整句子。
- 复用 `invokeService`；`transcribe` 增加可选 `requireTimestamps`，视频调用要求真实时间戳。兼容适配器按需请求 `verbose_json`，其他插件保留各自协议。
- 校验时间戳并转换为视频全局时间，无词级时间不伪造；一个块可以返回多句，每句保留最终音频区间。
- 原文先提交，译文后更新，复用断句、翻译、增量列表、查词及导出。识别失败复用音频重试，翻译失败只重试译文。

## 调度与生命周期

- 独立协调器管理下载、解码、识别、缓存与状态，不塞入原生 CC 获取恢复逻辑。
- 同视频一个下载请求、一个 ASR 调用；PCM/WAV 最多两个有效最大时长，待落盘数据最多 16 MiB，采用背压。
- `seeking` 停止旧位置排队，`seeked` 合并 200 毫秒跳转并提升新位置优先级，保留成功结果。
- 有字幕立即显示，有压缩音频直接解码，否则优先获取目标附近媒体段；从头降级时等待顺序下载到目标。解码前置样本不作为 ASR 上下文，首块允许半句话。
- 当前区间至结尾优先，随后补齐前段字幕；音频下载同步补齐整轨，不重复请求已缓存段。
- 所有异步结果和持久写入绑定视频、音轨、服务及会话版本；不能取消的后端任务不绕过服务并发限制，迟到结果不能串入新任务。
- 切翻译服务复用 ASR 原文；换视频或音轨隔离旧结果。关闭侧栏不停止任务，关闭 ASR、扩展翻译或页面则停止。
- 原生 CC 关闭不取消 ASR；不自动播放、暂停或跳转视频。

## 持久字幕与临时音频

### 持久字幕

- 扩展 IndexedDB 保存视频、音轨、源语言、时长、可取得的媒体版本、原始 ASR 分段、最终字幕和译文，以及已检查/成功/失败/未处理区间。
- 保存识别、断句、翻译配置签名及格式版本；逐块成功即原子落盘，不等整片完成。
- 静音计入检查覆盖，整片无失败缺口才标记双语字幕完整。
- 默认 200 MiB，按最久未访问视频淘汰，不按时间自动过期；提供删除当前视频和清空入口。
- 并行读取缓存和确认媒体身份；完整命中零服务调用，部分命中先显示再按优先级补齐。
- 音轨、媒体版本或时长不匹配不复用；ASR 配置变化失效原文，断句变化只重处理原文，翻译配置变化只失效译文。
- 密钥、超时、分块时长不使已完成字幕失效；不存密钥、token、签名地址，不同步字幕正文。
- 损坏只清理相关记录，磁盘写入失败保留当前显示并提示未保存。

### 临时音频

- 单独保存压缩段、初始化信息及时间索引，不长期保存 PCM；每视频 512 MiB、总计 1 GiB，同时遵守实际配额。
- 配额不足暂停并提示，不申请额外权限、不误报完成。
- 换视频、音轨、关闭任务或页面时清理；扩展启动清理失去活动页面关联的遗留音频。
- 删除音频不删除字幕；字幕命中不表示音频存在。

## 音频下载交互

| 操作 | 只有字幕缓存时 |
| --- | --- |
| 打开、播放、拖动 | 直接显示已有字幕，缺失字幕区间才补识别翻译 |
| 下载一句 | 优先获取相交媒体段及初始化信息；从头降级时获取至句末再裁剪，不调用 ASR/翻译 |
| 下载完整音频 | 获取整条当前匹配音轨，显示进度，不调用 ASR/翻译 |
| 音频获取失败 | 显示重试，缓存字幕不受影响 |

- 重取前从播放器取得新参数，校验原音轨及版本；不可用或不匹配明确失败，不替换配音。
- ASR 字幕行提供“下载本句音频”或“获取并下载本句音频”；无音频时仍可点击，显示准备/失败/重试。
- 按最终句子时间裁剪，跨段解码并衔接，导出原采样率/声道 WAV，不加留白或生成配音。时间精度受 ASR 结果限制。
- 同句重复点击合并，同时一个句子导出；不触发跳转、查词或收藏，邻近句子复用临时音频。
- 顶部“下载完整音频（M4A）”复用首次下载；字幕命中后点击才下载。实际媒体时间覆盖计算进度，未知总长显示时长/字节。
- 无缺段后重封装原 AAC，保留静音，不转码、不直接拼接碎片。封装显示独立状态，不与字幕进度混用。
- 首次取消下载停止依赖它的 ASR；独立导出取消不影响字幕。使用现有下载机制，不加 downloads 权限。
