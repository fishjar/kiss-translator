KISS Translator（简约翻译）是一款简约、高效、开源免费的双语对照翻译浏览器扩展，支持网页双语翻译、YouTube 双语字幕、划词查词、输入框翻译、网页图片与截图翻译、PDF/EPUB 文档翻译以及端侧本地 AI 离线翻译，帮助你顺畅阅读外文网页、论文、电子书与视频内容。

【核心翻译场景】
• 网页双语对照翻译：智能识别正文区域，保留富文本排版，支持多种自定义译文样式及「仅显示译文（隐藏原文）」模式，阅读外文资讯、技术文档与社交媒体更轻松。
• 划词查词与悬停翻译：选中文字即可呼出翻译浮窗，支持鼠标悬停段落翻译、柯林斯与内置英文词典查词、生词本收藏，并支持多服务横向对比窗口与可选剪贴板自动翻译。
• 输入框即时翻译：在任意网页输入框中用外语回复邮件、评论或聊天，按下快捷键即可一键翻译替换。
• 网页图片与截图翻译：支持网页图片悬停识别翻译以及屏幕区域截图翻译，轻松看懂图表、漫画与海报文字。
• YouTube 双语字幕与语音转写：支持智能合并字幕、AI 语义断句与 ASR 语音转写生成字幕，提供双语字幕叠加、完整字幕对照列表、字幕悬停查词、生词收藏及 AI 视频内容总结。

【文档与图片文件翻译】
• 多格式文件翻译：支持 TXT、Markdown、PDF、EPUB 电子书及 PNG/JPEG/WebP 图片翻译，各阶段可自由指定专用翻译、OCR 文字识别、版面分析与公式/表格解析服务。
• PDF 与 EPUB 深度处理：PDF 支持版面检测、公式/表格解析、分阶段翻译缓存，导出 Markdown、单文件 HTML 或 ZIP 资源包；EPUB 支持按章或整本批量翻译，导出双语或纯译文 EPUB。

【海量内置服务、本地 AI 与接口插件】
• 丰富翻译与 AI 接口：内置 Google、Microsoft、DeepL/DeepLX、Baidu、Tencent、Volcengine、Yandex、Qwen-MT，以及 OpenAI、Gemini、Claude、DeepSeek、Ollama、SiliconFlow、AliyunBailian、OpenRouter、AzureAI、CloudflareAI 等服务，支持批量聚合翻译、流式输出、上下文记忆、专业术语库与自定义提示词模板。
• 端侧本地 AI（隐私离线运行）：内置模型中心，支持 WebGPU/CPU 硬件加速，提供本地 LLM 文本翻译、VLM 图像理解、OCR 识别、ASR 语音识别、TTS 语音合成与文档版面分析，模型下载后全程离线运行，保护数据隐私。
• 开放接口插件体系：支持联网安装官方插件或导入外部插件，自由对接任意非标准 API；插件网络请求严格限制在声明域名范围内，授权仅保存于本机。

【规则引擎与多端同步】
• 智能规则与可视化选取：支持个人规则、订阅规则与全局规则三级优先级覆盖；内置可视化网页元素选取器，实时高亮预览翻译范围。
• 加密跨设备同步：支持通过自建 KISS-Worker（Cloudflare Workers / Docker）、标准 WebDAV 或 GitHub Gist 同步全量配置与生词本，并支持同步数据加密。

【默认快捷键】
• Alt+Q：开启或切换网页翻译（扩展全局默认）
• Alt+D：打开独立多服务对比翻译窗口（扩展全局默认）
• Alt+K：打开设置浮窗（扩展全局默认）
• Alt+S：打开划词翻译弹窗（扩展全局默认）
• Alt+I：翻译当前输入框内容（页面内快捷键）
• Alt+O：打开完整设置页（页面默认，扩展全局可在浏览器快捷键页绑定）
提示：截图翻译、仅显示译文、切换译文样式等更多命令均可在浏览器扩展快捷键管理页自由绑定。

KISS Translator 基于 GPL-3.0 协议完全开源，不收集或出售用户浏览记录与个人隐私数据；云端翻译请求直连你所配置的接口服务，端侧本地 AI 全程离线计算。
