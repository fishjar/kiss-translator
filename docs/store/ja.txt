KISS Translator（シンプル翻訳）は、ウェブページの対訳表示、YouTube 対訳字幕、選択テキストの辞書検索、入力欄翻訳、ウェブ画像・スクリーンショット翻訳、PDF/EPUB ファイル翻訳、さらに端末完結型のローカル AI オフライン翻訳に対応した、シンプルで高機能なオープンソース翻訳拡張機能です。

【主な翻訳シーン】
• ウェブページの対訳翻訳：本文エリアを自動検出し、リッチテキストのレイアウトを保ったまま対訳表示。カスタム訳文スタイルや「訳文のみ表示（原文を非表示）」モードにも対応しています。
• 選択語句の検索とホバー翻訳：テキストを選択してポップアップ翻訳、段落へのマウスホバー翻訳、内蔵・Collins 英英辞書検索、単語帳登録、複数サービスの比較ウィンドウ、任意のクリップボード自動翻訳を利用できます。
• 入力欄の即時翻訳：メールやコメント、チャット入力欄で母国語のまま入力し、ショートカットひとつで外国語に翻訳できます。
• ウェブ画像・スクリーンショット翻訳：ウェブ上の画像ホバー翻訳や画面の範囲指定スクリーンショット翻訳に対応し、図表やポスター、漫画の文字もスムーズに理解できます。
• YouTube 対訳字幕と音声文字起こし：スマート字幕結合、AI による自然な文脈区切り、さらに ASR 音声文字起こしによる字幕生成に対応。字幕のホバー辞書検索、単語帳保存、字幕一覧、AI 動画要約も利用可能です。

【ドキュメント・画像ファイル翻訳】
• マルチフォーマット対応：TXT、Markdown、PDF、EPUB 電子書籍、PNG/JPEG/WebP 画像の翻訳に対応。翻訳、OCR 文字認識、レイアウト解析、表・数式解析にそれぞれ最適なサービスを個別に割り当てられます。
• PDF・EPUB の高度な処理：PDF はレイアウト検出や表・数式解析を行い、Markdown・単一 HTML・ZIP 形式で出力可能。EPUB は章単位または書籍全体を一括翻訳し、対訳版または翻訳版 EPUB として保存できます。

【豊富な内蔵サービス・ローカル AI・プラグイン】
• 多彩な翻訳・AI サービス：Google、Microsoft、DeepL/DeepLX、Baidu、Tencent、Volcengine、Yandex、Qwen-MT をはじめ、OpenAI、Gemini、Claude、DeepSeek、Ollama、SiliconFlow、AliyunBailian、OpenRouter、AzureAI、CloudflareAI、ブラウザ内蔵 AI などに対応。バッチ翻訳、ストリーミング出力、会話コンテキスト、用語集、カスタムプロンプトをサポートします。
• ローカル AI（完全オフライン・プライバシー保護）：内蔵のモデルセンターから WebGPU/CPU 向けモデルを取得し、LLM 翻訳、VLM 画像理解、OCR、ASR 音声認識、TTS 音声合成、文書レイアウト解析をすべてローカル端末上でオフライン実行できます。
• 柔軟な API プラグイン機構：公式・外部プラグインを簡単に導入して非標準 API にも対応可能。通信先は宣言されたドメイン範囲に制限され、権限承認は端末ローカルに安全管理されます。

【ルール管理と暗号化同期】
• スマートルールと視覚的セレクター：個人ルール・購読ルール・グローバルルールの 3 段階優先度に対応。ページ上で要素を直接選び、翻訳範囲をハイライト確認しながら編集できます。
• マルチデバイス同期：セルフホスト型 KISS-Worker（Cloudflare Workers / Docker）、WebDAV、または GitHub Gist による全設定・単語帳の同期に対応し、暗号化同期も利用できます。

【デフォルトショートカット】
• Alt+Q：ウェブページ翻訳のオン / オフ（拡張グローバル既定）
• Alt+D：独立した複数サービス比較ウィンドウを開く（拡張グローバル既定）
• Alt+K：設定ポップアップを開く（拡張グローバル既定）
• Alt+S：選択テキスト翻訳パネルを開く（拡張グローバル既定）
• Alt+I：現在の入力欄を翻訳（ページ内ショートカット）
• Alt+O：詳細設定ページを開く（ページ既定・ブラウザのショートカット設定でグローバル割り当て可）
ヒント：スクリーンショット翻訳、訳文のみ表示、スタイル切替などの追加コマンドもブラウザの拡張機能ショートカット設定から自由に割り当てられます。
