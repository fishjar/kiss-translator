KISS Translator（簡約翻譯）是一款簡約、高效、開源免費的雙語對照翻譯瀏覽器擴充功能，支援網頁雙語翻譯、YouTube 雙語字幕、劃詞查詞、輸入框翻譯、網頁圖片與截圖翻譯、PDF/EPUB 文件翻譯以及本機端側 AI 離線翻譯，助你輕鬆閱讀外文網頁、學術論文、電子書與影片。

【核心翻譯場景】
• 網頁雙語對照翻譯：智慧辨識正文區域並保留富文本排版，提供多種自訂譯文樣式及「僅顯示譯文（隱藏原文）」模式，閱讀外文新聞、技術文件與社群媒體更流暢。
• 劃詞查詞與懸停翻譯：選取文字即刻彈出翻譯浮窗，支援滑鼠懸停段落翻譯、柯林斯與內建英文詞典查詞、生詞本收藏，並提供獨立多服務對比視窗與可選剪貼簿自動翻譯。
• 輸入框即時翻譯：在任意網頁輸入框中撰寫外語郵件、留言或訊息，按下快捷鍵即可一鍵翻譯替換。
• 網頁圖片與截圖翻譯：支援網頁圖片懸停辨識翻譯與螢幕區域截圖翻譯，快速讀懂圖表、漫畫與海報文字。
• YouTube 雙語字幕與語音轉寫：支援智慧合併字幕、AI 語意斷句與 ASR 語音辨識生成字幕，提供雙語字幕疊加、完整字幕對照清單、字幕懸停查詞、生詞收藏及 AI 影片內容摘要。

【文件與圖片檔案翻譯】
• 多格式檔案翻譯：支援 TXT、Markdown、PDF、EPUB 電子書及 PNG/JPEG/WebP 圖片翻譯，各階段可獨立指定專用翻譯、OCR 文字辨識、版面分析與公式/表格解析服務。
• PDF 與 EPUB 深度處理：PDF 支援版面偵測、公式與表格解析、分階段翻譯快取，可匯出 Markdown、單檔 HTML 或 ZIP 資源包；EPUB 支援單章或整本批次翻譯，匯出雙語或純譯文 EPUB。

【豐富內建服務、本機 AI 與介面外掛】
• 多元翻譯與 AI 服務：內建 Google、Microsoft、DeepL/DeepLX、Baidu、Tencent、Volcengine、Yandex、Qwen-MT，以及 OpenAI、Gemini、Claude、DeepSeek、Ollama、SiliconFlow、AliyunBailian、OpenRouter、AzureAI、CloudflareAI 等服務，支援批次聚合翻譯、串流輸出、上下文記憶、專業術語庫與自訂提示詞範本。
• 端側本機 AI（隱私離線運算）：內建模型中心，支援 WebGPU/CPU 硬體加速，提供本機 LLM 文本翻譯、VLM 圖像理解、OCR 辨識、ASR 語音辨識、TTS 語音合成與文件版面分析，模型下載後全程離線執行，守護資料隱私。
• 開放介面外掛體系：支援線上安裝官方外掛或匯入外部外掛，彈性串接任意非標準 API；外掛網路請求嚴格受限於宣告的網域範圍，授權僅儲存於本機。

【規則引擎與跨裝置同步】
• 智慧規則與視覺化選取：支援個人規則、訂閱規則與全域規則三層優先級覆蓋；內建視覺化網頁元素選取器，即時高亮預覽翻譯範圍。
• 加密跨裝置同步：支援透過自建 KISS-Worker（Cloudflare Workers / Docker）、標準 WebDAV 或 GitHub Gist 同步完整設定與生詞本，並支援同步資料加密。

【預設快捷鍵】
• Alt+Q：開啟或切換網頁翻譯（擴充全域預設）
• Alt+D：開啟獨立多服務對比翻譯視窗（擴充全域預設）
• Alt+K：開啟設定浮窗（擴充全域預設）
• Alt+S：開啟劃詞翻譯彈窗（擴充全域預設）
• Alt+I：翻譯目前輸入框內容（頁面內快捷鍵）
• Alt+O：開啟完整設定頁（頁面預設，擴充全域可於瀏覽器快捷鍵頁綁定）
提示：截圖翻譯、僅顯示譯文、切換譯文樣式等更多指令皆可在瀏覽器擴充快捷鍵管理頁自由設定。
