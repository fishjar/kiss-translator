# 提示词执行规则

普通 AI 翻译、词典和摘要按整对模板执行。原始系统和用户模板均为空时使用完整默认模板对；缺失、null、空字符串和纯空白均为空。任意一边有内容时保留整对自定义模板，不从默认模板补另一边。

默认选择顺序为有效选定预设、插件对应能力默认预设、宿主对应任务默认模板。批量模板匹配 JSON、line 或 XML 协议，单句使用 text 协议。SDK 直接调用也支持空模板对回退，属于 Plugin API 1。旧实例的表单默认空字段不会遮住默认模板；运行时解析不迁移或覆盖存储。

单句翻译和词典使用 `{{text}}`，批量翻译使用 `{{segments}}`，原生摘要使用 `{{transcript}}`。自定义模板只展开显式占位符，不自动追加原文、术语和语气。系统和用户模板均可承载输入。占位符只展开一次，输入中的占位符和 `$` 字符按字面保留；未知占位符保留，缺失值为空，静态说明保留。

自定义模板原始内容非空、展开后两条消息均为空白时，在请求前返回 `INVALID_INPUT`，不再回退默认模板。原生视频总结的空模板对回退到默认视频总结模板；自动字幕上下文摘要使用包含标题、简介和字幕的专用默认模板。原生和 SDK 摘要均删除空占位符独立行。

配置解析、词典面板、生词本及能力测试采用相同规则。默认模板在缓存签名前解析，缓存跟随实际模板和参数。摘要能力测试优先使用当前总结场景模板，然后选择服务 summary 预设或内置总结模板。

请求编码省略空文本消息，保留有效图片和音频。OpenAI 兼容协议允许纯系统消息；Claude Messages 和 Gemini 原生协议缺少有效对话内容时返回 INVALID_INPUT，不添加占位文字或移动角色。

传统翻译接口、Qwen-MT 原生字段、BuiltinAI 专用 API、聊天 messages、字幕固定 JSON 和图片输入保持各自协议。字幕保留 SDK 输出格式约束，不新增可编辑的字幕用户模板。
